 # Haulectra

## ↳ Deskripsi Singkat 
Haul adalah aplikasi toko online yang membantu pemilik toko mengelola jualannya di satu tempat, sekaligus memudahkan pelanggan berbelanja tanpa harus datang ke toko. Pelanggan bisa melihat katalog produk, memasukkan barang ke keranjang, memakai voucher diskon, memilih metode pembayaran, dan melacak pesanannya sampai paket tiba. Sementara itu, admin toko bisa mengelola produk dan stok, mengatur promo, memantau pesanan dan pengiriman, serta melihat data pelanggan
